## Work completed and artifacts

The new public app is the default production entry, with season-authoritative
URLs and isolated typed query states. It reads WP03 approved pointers instead
of legacy prediction/model selectors. DTO projection excludes research metadata;
historical labels never use today's mutable roster. Unknowns remain nullable,
errors are visible/retryable, loading removes retained percentages, and the
full field includes unknown entries without unsupported ranks/totals.

Production uses the approved fonts/tokens and shared Panel, compact responsive
navigation, horizon controls, metadata context and accessible timing tables.
Large charts and the retained rollback UI are lazy modules. Static assets serve
through Nginx with deep-link fallback and API-prefix-only proxying. Font licenses
accompany distribution assets. No runtime sample fixture or real-data forecast
has been invented; the explicit synthetic fixture builder refuses existing DBs.

Contract/component/rollback handoff: [PUBLIC_V1.md](../api/PUBLIC_V1.md).
Evidence: [README](../design/evidence/wp11/README.md), `browser.json` (33 checks,
zero page errors), `postgres.json` (seven checks), `packaging.json`, and nine
JPEG screenshots at that location. No model-quality evidence is claimed.

## Decisions and blockers

WP11-local contract decisions are explicit in PUBLIC_V1.md: publication pointer
is approval; entry keys bind exact persisted event-entry IDs; date-valid aliases
are the only historical display source; unavailable is a successful selection;
unknown counts remain null; ranker confidence is never converted to probability.
No shared model/migration/interface allocation or cross-package decision changed.

No implementation blocker. Limitations: temporal colors are absent from the
integrated schema, so neutral strips are intentional; unresolved producer entry
bindings fail visibly; no live published dataset was available/tested; legacy
results show an unavailable view; `stale` is typed but awaits a source-specific
policy; font subsetting remains optional optimization. Normal registry-based
container build was unavailable due external metadata timeout, while actual
compiled assets/Nginx behavior passed. No deployment is authorized.

## Migration, backfill and rollback

No schema change, backfill, forecast write or real database mutation. Public
reading behavior switches to publication-only DTOs. Legacy UI is retained with
build-time `VITE_GRIDORACLE_LEGACY_UI=1`; legacy API routes require
`GRIDORACLE_LEGACY_API=1` on a private/local operator service. Public builds
leave both flags off. Revert WP11/rebuild the previous release for serving
rollback; retain all immutable database history. No data deletion is required.
Disposable browser/PostgreSQL fixtures and local container runtimes are test
infrastructure only; both disposable containers were stopped after evidence
capture. Local preview/API processes are stopped before handoff.
