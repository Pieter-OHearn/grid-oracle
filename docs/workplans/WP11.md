## Work completed and artifacts

The new public app is the default production entry, with season-authoritative
URLs and isolated typed query states. It reads WP03 approved pointers instead
of legacy prediction/model selectors. DTO projection excludes research metadata;
historical labels never use today's mutable roster. Unknowns remain nullable,
errors are visible/retryable, loading removes retained percentages, and the
full field includes unknown entries without unsupported ranks/totals.

Production uses the approved fonts/tokens and shared Panel, compact responsive
navigation, horizon controls, metadata context and accessible timing tables.
Large charts and the retained rollback UI are lazy modules. Static assets serve
through Nginx with deep-link fallback and API-prefix-only proxying. Font licenses
accompany distribution assets. No runtime sample fixture or real-data forecast
has been invented; the explicit synthetic fixture builder refuses existing DBs.

Contract/component/rollback handoff: [PUBLIC_V1.md](../api/PUBLIC_V1.md).
Evidence: [README](../design/evidence/wp11/README.md), `browser.json` (33 checks,
zero page errors), `postgres.json` (seven checks), `packaging.json`, and nine
JPEG screenshots at that location. No model-quality evidence is claimed.
