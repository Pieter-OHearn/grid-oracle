Boundaries/known limitations:

- WP09 history is explored chronological reconstruction, out-of-sample relative
  to fitted weights, not pristine holdout/as-of/prospective. No new champion.
- No valid live prospective aggregate is stored; event-level published-run
  evaluations and missing weekends remain visible without invented aggregate scores.
- WP03 currently permits one approved run per horizon. Same-horizon unpublished
  revisions remain unavailable; the comparison exposes all approved snapshots,
  preserving fields/identities and suppressing incomparable deltas.
- Production evaluations require offline server-produced `wp12-v1` semantics
  and denominators. Generic legacy records are withheld; no producer job/backfill
  is silently introduced. There is no version-bound per-entry classification
  payload, so correction views compare stored outcome scores and never infer a
  corrected driver order from mutable legacy results.
- Per-feature attribution, a model-specific public card for arbitrary published
  runs and unsupported outcome probabilities are unavailable, explicitly labelled.
- Browser evidence uses synthetic runs/corrections and actual historical stored
  metrics. Native assistive technology/devices and live published-data validation
  remain release checks. No infrastructure mutation/deployment occurred.
