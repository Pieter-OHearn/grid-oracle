## Migration, backfill and rollback

Alembic is the versioned ledger. `scripts.db_migrate` refuses unknown/empty databases, stamps only the inspected legacy baseline, then adds identity/season/session/entry/revision/quarantine structures. Revision `20260929_03` assigns durable keys before PostgreSQL inserts and enforces them non-null; its temporal exclusion constraint prevents overlapping aliases while allowing a provider key in separate eras. A real upgrade requires an existing backup path. Rollback is: (1) `--downgrade-wp02`, (2) restore the pre-upgrade backup, (3) `--finalize-legacy-restore`, which verifies no additive tables remain before removing the baseline ledger. The complete sequence passed against the isolated fixture; its volume was removed. Do not run `pipeline.bootstrap` against a real database.
