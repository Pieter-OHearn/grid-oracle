## Decisions and blockers

WP04 `f2a722a` (PR #97) are ancestors of the claim base. D10, D11, D18, D19
and D22 govern this package. The source archive's retrieval timestamp is known,
but each original provider availability timestamp is not; every baseline row is
therefore marked `archived_retrieval_known_asof_unknown` and
`asof_eligible=false`. The baseline does not expand to 2018 because comparable
raw qualifying/result coverage was not supplied. Specific blockers: none.

## Migration, backfill and rollback

No database migration or live backfill was run. The offline backfill creates
additive content-addressed dataset roots; an existing matching checkpoint is
verified and reused, while a mismatch fails rather than overwrites it. Rollback
is to stop selecting this manifest/version or pin a prior manifest; raw archive
snapshots remain the reconstruction input. See the data card for the exact CLI.
