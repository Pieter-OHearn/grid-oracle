model. WP02 integration was confirmed: `ce9690e` is an ancestor of the claim
base `c780600`. Specific blockers: none.

## Migration, backfill and rollback

Revision `20260929_04` is additive; it leaves legacy reads untouched. A future
operator may import old prediction values with known timestamps via
`import_legacy_forecast`, which labels them `legacy_unverified` and records
unknown lineage rather than inventing it. No backfill was run. Normal rollback
stops new-contract reads/writes while retaining immutable history. Alembic
downgrade drops the additive tables and therefore requires a verified
pre-upgrade backup/restore; it is not a routine production rollback.
